# RDM Radio Mobile – Downloads

Internet radio for Android phones: Egyptian, Arab and international stations, a 10-band
equalizer, prayer times with the Azan, and the Ramadan Imsakiyya.

This repository only publishes the app. It contains no source code.

## Install
1. Open the [latest release](../../releases/latest) on your phone.
2. Download `RDM-Radio-Mobile-<version>.apk` and open it. Allow "Install unknown apps" if Android asks.

RDM Radio Mobile (`com.rdm.radiomobile`) installs next to RDM Radio for cars; they don't replace each other.

Already installed? Settings → Check for updates tells you when a new version is out.

## Verify a download
Every release includes `SHA256SUMS` with the APK's SHA-256.
Check on a computer: `apksigner verify --print-certs RDM-Radio-Mobile-<version>.apk`
